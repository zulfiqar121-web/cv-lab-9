# YOLOv8 Computer Vision Applications

This repository contains different computer vision case studies built using YOLOv8, OpenCV, and Python. The project focuses on real world object detection applications and demonstrates how AI can be used in surveillance, retail, education, wildlife monitoring, and industrial environments.

## Project Overview

The notebook includes the following applications:

* Real Time Traffic Surveillance System
* Public Park Surveillance Analysis
* Video Based Object Detection
* Retail Checkout Automation
* Smart Classroom Monitoring
* Smart Parking Surveillance System
* Wildlife Conservation Monitoring
* Industrial Defect Detection
* Retail Shelf Monitoring and Analytics

Each task uses YOLOv8 for detecting and identifying objects from images or videos.

## Technologies Used

* Python
* YOLOv8
* OpenCV
* Matplotlib
* MoviePy

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/your-repository-name.git
cd your-repository-name
```

Install the required libraries:

```bash
pip install ultralytics opencv-python matplotlib moviepy
```

## How to Run

1. Open the notebook in Jupyter Notebook or Google Colab.
2. Update the image or video paths according to your system.
3. Run the cells one by one.
4. The detection results will be displayed with bounding boxes and labels.
